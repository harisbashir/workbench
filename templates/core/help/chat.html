Chat

Kinds of conversation

KindWho sees it
Project channelsCreated automatically with each project. Everyone on the project sees it. GitHub and task updates are posted here.
Public channelsAnyone can find and join them — good for #general, #firmware, #suppliers.
Private channelsOnly the members chosen when it was created.
Direct messagesJust you and one other person. Start one with “Message someone…” in the chat sidebar.

Sending messages

  • Enter sends, Shift+Enter adds a new line.
  • @username notifies that person.
  • Task IDs such as PWR-12 turn into links.
  • **bold**, `code` and ```code blocks``` for register dumps or logs.
  • Hover over your own message to edit or delete it.

New messages appear within a few seconds. The number next to Chat in the menu shows unread messages.

Chat or comment?

Use chat for quick questions. Anything someone will need to find later — a design decision, review feedback, a test result — belongs in a task comment.

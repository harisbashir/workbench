What happens automatically

  • PR opened → linked tasks move to In review and the reviewer is notified
  • Changes requested → task goes back to In progress
  • PR merged → linked tasks move to Done
  • CI (e.g. KiBot ERC/DRC) fails → assignee notified, message in project chat
  • Pushes to the main branch → summary in project chat

# Security policy

## Reporting a vulnerability

Please report security problems **privately** through GitHub: open this repository's
**Security** tab and choose **Report a vulnerability**. Don't open a public issue for them.

Include what you found, how to reproduce it, and which version you tested (`cat VERSION`).
You'll get an answer as soon as possible, and a fix will be released as a new version tag
that servers pick up with `./update.sh`.

## Supported versions

Only the newest release receives security fixes. Keep servers up to date with `./update.sh`.

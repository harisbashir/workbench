Good to know

  • Files are always downloaded through Workbench, so permissions are checked the same way wherever they're kept. Buckets stay private.
  • Moving copies every file and checks it before switching. Nothing is deleted from the old place, and a move that's interrupted can simply be started again.
  • Locked storage can't be changed from this page. To unlock it, run this on the server:
    docker compose exec workbench manage storage --unlock
  • Backups still include every file. With cloud storage, a copy of each backup is also kept in the bucket under backups/.
  • Access keys are stored encrypted.
Storage guide

Which option?

Folder on this server — simplest; fine until the disk fills up. Point it at a bigger disk or a NAS share when needed.

Amazon S3 — best if Workbench runs on AWS. Pay per GB; no disk to manage.

Cloudflare R2, Backblaze B2, Wasabi — S3-compatible and usually cheaper; R2 has no download fees.

DigitalOcean Spaces, Google Cloud Storage — handy if the server already runs there.

MinIO or a NAS with an S3 server — keep files in the office on your own hardware.

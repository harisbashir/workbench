Files

Workbench has its own file library, so documents don't get scattered across email, WhatsApp and personal drives.

Spaces and folders

  • Each project has a space, visible only to people on that project. Use it for test reports, scope captures, manufacturing files and meeting notes.
  • Shared is company-wide. Use it for datasheets, templates, procedures and policies.
  • Make folders inside a space however you like, for example Datasheets, Test reports / Rev B or Manufacturing.

Uploading

Drag files anywhere onto a folder page, or choose choose files. You can upload many files at once, and a progress bar shows how far along the upload is.

Files attached to a task are saved in Task files / PWR-12, and files shared in a chat channel go to Chat uploads. Everything ends up in one place.

Versions — nothing gets overwritten

Upload a file with the same name into the same folder, or use Upload a new version on the file's page, and it becomes the next version. Every older version stays available to download, with who uploaded it, when, and an optional note about what changed. A SHA-256 fingerprint lets you check two copies are identical.

Previews

PDFs, images and text files (CSV, logs, source code, KiCad text files) open right in the browser. Other types download.

Deleting and restoring

Deleted files go to the Trash, where anyone who can edit the project can restore them. They're removed automatically after the number of days set in System → Backups & storage (30 by default).

Where files live on the server

For administrators: every file is stored in the server's data/files folder, sorted by project (data/files/PWR/…, data/files/shared/…). They're ordinary files, so you can see and copy them directly. Change them through Workbench, though, so versions and permissions stay correct. Files → Storage shows what's using space and can clean up old versions.

Blocked file types

Files that could run in a browser or on a computer (.html, .js, .exe, scripts…) can't be uploaded, to protect the team. Zip them first if you really need to share one.

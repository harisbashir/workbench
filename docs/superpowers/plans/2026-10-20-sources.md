# Sources (1.6.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "Sources" section where each project and board keeps versioned repositories of code and KiCad files: browser check-in with a preview, history, compare with line diffs, highlighted code viewer, KiCad check-out locks, stale-file protection, zip downloads, and promoting a version to a firmware release or a board revision.

**Architecture:** New app `apps/sources`. File contents are stored once per SHA-256 as `Blob` rows whose files live in Django storage (`sources/blobs/ab/cd/<sha>`), so local disk and S3 both work. A `Version` lists its full tree as `VersionFile(path → blob)`. Uploads are first staged into a `Draft` (a JSON manifest of path → blob id), previewed, then committed by `checkin.commit()` under `select_for_update` on the repository. Pure logic lives in `intake.py` (uploads/zips → staged files), `checkin.py` (plan + commit + locks), `diff.py` (compare) and `highlight.py` (Pygments); views stay thin.

**Tech Stack:** Django 5.2, Pygments (new dependency), server-rendered templates, one small `static/js/sources.js` for folder uploads.

**Spec:** `docs/superpowers/specs/2026-10-19-sources-and-controllers-design.md` (Part 2).

## Global Constraints

- Strict CSP: no inline `<script>`, `style=` or `on*=`; JS in `static/js/sources.js`, styles in `static/css/app.css` (Pygments token classes included, light + dark).
- Permissions: everything is looked up through its project (`Project.objects` by key → `can_view`/`can_edit`); other-project ids 404. Viewers browse and download; writers (`project.can_edit`) check in, lock and create repositories; `user.can_manage_projects` breaks other people's locks and deletes repositories.
- Files only through the storage API; downloads through permission-checked views with `X-Content-Type-Options: nosniff`; previews never serve HTML/SVG/JS inline.
- Limits: per file `SiteSettings.load().max_upload_mb` MB; per check-in total `settings.MAX_UPLOAD_MB` MB; max 5,000 files per check-in; path max 400 chars; zip: no absolute paths, `..`, backslashes or symlinks, compression ratio ≤ 100 per entry; `BLOCKED_EXTENSIONS` refused.
- Ignored on upload: `.git/`, `__pycache__/`, `*-backups/`, `*.kicad_prl`, `fp-info-cache`, `_autosave-*`, `~*.lck`, `.DS_Store`, `Thumbs.db`, `__MACOSX/`.
- Locks required for `.kicad_sch` and `.kicad_pcb` changes/deletes; honoured on any path someone holds.
- Audit: `sources.repo_created`, `sources.repo_updated`, `sources.repo_deleted`, `sources.checkin`, `sources.lock`, `sources.unlock`, `sources.lock_broken`, `sources.promote`.
- Diff limits: 1 MB per side, 20,000 lines, 2 s; highlight limit 1 MB / 20,000 lines.
- `Pygments>=2.18,<3` in requirements.txt.
- `DATA_UPLOAD_MAX_NUMBER_FILES = 1000` (folder uploads); larger check-ins go as a zip.
- UI text plain and friendly. Tests for everything in `apps/sources/tests/`.

## Review Focus

1. **Path tricks** in loose uploads and zip entries (`../`, `/abs`, `C:\x`, backslashes, NUL, very long, duplicate paths differing only in case) → refused or normalised; nothing written outside the repo tree. Test: Task 2 `test_paths_normalised_and_refused`.
2. **Two people checking in on the same base** → second check-in's overlapping files are refused as stale; version numbers never collide. Test: Task 3 `test_stale_file_refused`, `test_numbers_sequential_under_lock`.
3. **Binary or huge files** in the viewer and compare → no crash, shown as "binary"/"too large" with downloads. Tests: Task 4 `test_binary_file_view`, Task 5 `test_large_file_not_diffed`.
4. **Viewer or outsider** on every sources URL (GET and POST) → read-only or 404. Test: Task 4 `test_permissions_matrix`.
5. **Draft abandoned or reused by another user** → only its author can confirm; drafts on a repository whose latest version moved are re-planned at confirm time. Test: Task 6 `test_draft_belongs_to_author`, `test_confirm_replans_against_latest`.

### Task 2: Upload intake (`apps/sources/intake.py`)

**Interfaces — Produces:**
- `normalise_path(raw: str) -> str | None` — backslashes → `/`, strip leading `./` and `/`, collapse `//`, reject (return None) any segment `..`, NUL, drive letters (`C:`), empty result, or length > 400.
- `is_ignored(path) -> bool` — the Global Constraints ignore list.
- `Intake` result dataclass: `files: dict[str, Blob]`, `refused: list[tuple[str, str]]`.
- `take(uploads: list[tuple[str, UploadedFile]], into: str = "") -> Intake` — each item is (relative path or bare name, file). `.zip` uploads are expanded (paths inside kept, prefixed by `into`) unless the user ticked "keep zip as a file" (`take(..., keep_zips=True)`). Enforces: blocked extensions, per-file and total limits, 5,000 files, zip entry checks (symlink via `external_attr >> 16` S_IFLNK, ratio `file_size / max(compress_size,1) > 100`), duplicate paths case-insensitively (later wins, earlier refused "listed twice"). Ignored paths are dropped silently (counted in `ignored: int`).

### Task 3: Check-in engine and locks (`apps/sources/checkin.py`)

**Interfaces — Produces:**
- `tree(version) -> dict[str, Blob]` (empty dict for None).
- `needs_lock(path) -> bool` — `.kicad_sch` / `.kicad_pcb`.
- `Plan` dataclass: `added, changed, deleted, unchanged: list[str]`, `refused: list[tuple[str, str]]` (path, reason), `base: int`, `latest: int`, `new_tree: dict[str, Blob]`; property `has_changes`.
- `plan(repo, staged: dict[str, Blob], mode: str, base: int, user) -> Plan` — `mode="replace"` deletes paths missing from `staged`; `"update"` keeps them. Stale rule: a path the plan changes/adds/deletes whose blob differs between `tree(base)` and `tree(latest)` → refused "Changed by someone else since v{base} — download v{latest} and merge." Lock rule: `needs_lock(path)` and no lock by `user` → refused "Check out {name} first."; any lock by another user → refused "Checked out by {name}." Refused paths keep their latest content in `new_tree`.
- `commit(repo, staged, mode, base, message, user, *, allow_partial=False, release_locks=True) -> (Version | None, Plan)` — `transaction.atomic()`, `Repository.objects.select_for_update().get(pk=…)`, re-plan against the locked latest; return `(None, plan)` if `plan.refused and not allow_partial` or `not plan.has_changes`; else create Version (number = latest+1, parent = latest version, counters; line counts from `diff.count_lines` for text blobs ≤ 1 MB), bulk-create VersionFiles, update `latest_number`, delete the user's locks on committed paths if `release_locks`.
- `lock(repo, path, user) -> str | None` (error text), `unlock(repo, path, user, *, force=False) -> bool`. Lock only paths present in the latest tree; `IntegrityError` → "Checked out by {other}".
